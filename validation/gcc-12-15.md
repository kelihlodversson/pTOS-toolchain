# GCC 12–15 bugfix releases

These recipes add GCC 12.5.0, 13.5.0, 14.4.0 and 15.3.0, rebasing the
CrossMiNT patches for 12.4.0, 13.4.0, 14.3.0 and 15.2.0 respectively.
Official GNU archives and all local patches are checksum-pinned. GCC 16.2.0
remains the default; these releases can be selected in the CLI and manual CI.

The original archived patches are unchanged. The ports retain the full patch
contents, including other language runtime changes, although this SDK builds
C only. GCC 15.3's chrono header needed six remaining `__out` identifiers
renamed after three hunks encountered upstream context changes.

Source preparation is checked for m68k, ARM and x32. Compiler, SDK and pTOS
validation results will be recorded below once completed.
